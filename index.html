The browser never marks a payment as successful. Only the server callback plus Daraja verification can update a payment.

Payment security

  1. Daraja secrets stay in Firebase Functions secrets.
  2. Each checkout is stored with a unique CheckoutRequestID before a callback is processed.
  3. Callbacks are idempotent and queried server-to-server before entitlement is granted.
  4. Production onboarding must confirm Daraja's current callback and transaction-query behaviour with Safaricom.
